## Контракт сохранения и повторы

Worker проверяет CORS/Origin, TEST_ONLY/TEST_KEY, закрытые флаги, поля/согласие/версию, honeypot/размер, лимиты и настоящий Turnstile hostname/action. Timestamp+payload подписываются HMAC. Apps использует ScriptLock, PREPARED и фиксированную строку, затем SAVED. Ответ содержит подписанную save-confirmation с UUID, digest и временем. Worker проверяет её и результат UPDATE D1 с RETURNING перед saved=true браузеру. ContentService redirect 301/302/303 выполняется одним GET только на разрешённый Google-host, без тела/ключей; HTTP/JSON/подпись/конфликт не превращаются в ложный успех.

Одинаковый UUID/поля не создаёт новую строку, изменённые поля — конфликт. Другой UUID с похожей заявкой получает DUPLICATE. ERASED/ERASING и D1 erasures предотвращают восстановление стёртой записи. При неизвестном результате клиент блокирует повтор и показывает UUID. Отдельная процедура read-only сверки — CONFIRMATION-RECOVERY.md; completed synthetic-восстановление не повторять.

Семь колонок Лист1 и тринадцать колонок MypageJournalV2 сохраняются. Пользовательский текст записывается как literal text. Base64 журнала не шифрование. Новая отдельная MypagePrivacyV1 хранит минимальные метаданные обслуживания/удаления. Физической сортировки/удаления строк при PREPARED/ERASING нет.

## Telegram — пока не отправлять

Новая версия отправляет только UUID, без полей кандидата. notifyExistingSyntheticOnce ограничена существующим UUID f20b1b0c-887a-43d4-b671-5a303d09ffc0 и существующей группой; нужны отдельные разрешающие Properties, закрытый приём, единственность/совпадение строки, отсутствие чужих ожидающих операций и прошлой попытки. Приёмка одного сообщения требует отдельного согласия; не выбирать широкую retryTelegram.

Неопределённая отправка/потеря фиксации sent требует needs_review; повтор после тайм-аута не делается. Явный 429 учитывает retry_after; общий лимит 5 сообщений/вызов, 10 попыток и backoff. Absolute exactly-once Telegram API не обещается. Message ID записывается отдельно для ранней очистки; неизвестные/старые сообщения и история Google требуют процедур из RETENTION-OPERATIONS.md. Автоудаление группы/права/условия канала проверить до включения уведомлений. Можно оставить Telegram полностью выключенным.
