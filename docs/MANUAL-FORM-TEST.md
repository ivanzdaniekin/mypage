## Рекомендуемый способ и границы проверки

Обычный Chrome → настоящая HTML-страница на GitHub Pages → настоящий Turnstile → сохранение одного JSON локально → локальный Node.js отправитель с X-Mypage-Test-Key → существующий Worker → Apps Script → Google Sheet.

TEST_KEY вообще не передаётся Chrome: не находится в HTML, JS, URL, localStorage, sessionStorage или IndexedDB. Node читает MYPAGE_TEST_KEY из существующего защищённого ~/.mypage-private/test.env и устанавливает заголовок в памяти своего процесса. В аргументах команды только пути файлов, не секреты. Заголовки, тело, токен и секрет не логируются. Это технически реализуемая ручная передача настоящего Turnstile token, не отключение проверки и не фиктивный токен.

**Важно:** проверяется формирование данных формы и вся серверная цепочка. Это НЕ проверка прямого браузерного fetch/CORS/HTTP-отправки production-формы. Без передачи ключа клиенту обычная HTML-форма не может сама поставить секретный заголовок. Поэтому выбран отдельный локальный отправитель, а не расширение браузера, TLS-перехват или средства сокрытия автоматизации.

## Один requestId и один POST

Страница создаёт один crypto.randomUUID на загрузку и позволяет один экспорт. Перезагрузка может создать другой UUID, поэтому окончательная защита — фиксированный локальный маркер:
`~/.mypage-private/manual-post-attempt.json`.

Отправитель создаёт его атомарно с wx и fsync ДО сети. Второй процесс/повтор запуска блокируется даже с другим UUID. Маркер не удаляется автоматически после успеха, HTTP-ошибки или тайм-аута. Единственный fetch — POST на фиксированный существующий endpoint; redirect:error; тайм-аут 25 секунд; повторов нет. Подтверждение успеха только при HTTP 2xx, saved:true и совпадении requestId. Ошибка/тайм-аут означает неизвестный исход до сверки Sheet/журнала/D1, а не разрешение повторить.

Маркер не хранит контактные поля, токен или ключ. Право начать новую попытку появляется только после отдельного разрешения и сверки результатов; удаление/архивирование маркера не входит в автоматическую работу скрипта.

## Граница гарантии выключения

Локальный маркер гарантирует запрет повторного запуска этого отправителя, но **не выключает облачные флаги**. У него намеренно нет административных ключей Cloudflare/Google. Поэтому гарантировать автоматический rollback при обрыве связи, закрытии чата или недоступности панели нельзя. До отдельного согласования TTL на сервере или независимого административного watchdog тест допустим только под непрерывным контролем владельца с готовыми панелями отключения. При недоступности управления тест не начинать. В рамках этой подготовки TTL/watchdog, облачные настройки и секреты не меняются.
